# Command-line reference

Generated by `scripts/gen-cli-reference.sh` from the `--help` output of `impulse` and `impulse-watch`. Do not edit by hand: `scripts/ci-local.sh` fails when this file is not what the script produces. For what each command does, in order and with the checks it makes, read [spec/CLI.md](../../spec/CLI.md); for the watcher, [spec/WATCH.md](../../spec/WATCH.md); for the IPST file format, [spec/IPST.md](../../spec/IPST.md). Error codes are indexed in [ERRORS.md](ERRORS.md).

Global rules that the help text does not repeat: mainnet is used only when `--network mainnet` is passed explicitly; a key is read only from a key file the user names on the command line, and never printed or logged; a trade above the value cap is refused (spec/CLI.md, "Value cap").

### `impulse`

```text
Impulse atomic DvP on Kaspa: terms, funding addresses and URIs, transaction builders, local signing, submission, decoding, settlement receipts

Usage: impulse [OPTIONS] <COMMAND>

Commands:
  xchain   Hashlock exchange against a counterpart HTLC on another chain (testnet only; spec/V2.md section 10.9)
  terms    Create trade terms
  address  Show a trade's vault addresses, and the funding URI and QR code of a native KAS leg
  verify   Check a funding URI against a terms file
  status   Report a transaction's acceptance; with --key-file, sign it as a settlement receipt
  receipt  Settlement receipts
  fund     Build an unsigned funding transaction for your leg
  settle   Build an unsigned settle (vault terms) or Direct transaction
  refund   Build an unsigned refund of one vault UTXO
  direct   Direct trades: the Direct refund, a cancellation after the expiry
  ipst     Sign, merge or write out Impulse partially signed transactions
  submit   Check a fully signed IPST again and submit it to your node
  decode   Fetch an accepted transaction from your node and decode the trades it spends
  tip      Show your node's network, virtual DAA score and sink
  key      Key files
  token    KCC-20 tokens: a template's pin check; on testnet only, a fresh token and a lookup
  frost    FROST threshold settlement authority: key generation, signing and aggregation (I13)
  v2       Template v2 trades of 2 to 10 legs (I16): terms, funding, settle, refund, signing
  linked   Opening and return trades described by one sheet (I22): repo and securities lending
  help     Print this message or the help of the given subcommand(s)

Options:
      --network <NETWORK>  Network to act on. Testnet unless mainnet is passed here explicitly [possible values: mainnet, testnet]
  -h, --help               Print help
  -V, --version            Print version

Non-custodial software: it holds no funds and no keys, and signing happens only on your machine. Nothing here is financial, legal or tax advice, or an offer to buy or sell anything. Impulse issues no asset or token. Issuer terms, transfer restrictions and sanctions obligations stay your own responsibility, and Impulse does not check them. Use only values you can lose.
```

##### `impulse xchain new`

```text
Seller: create hashlock terms with a fresh secret (written to --secret-out, never shown)

Usage: impulse xchain new [OPTIONS] --draft <FILE> --my-key <HEX> --my-counterpart-account <HEX> --counterpart-final-secs <SECS> --known-hashes <FILE> --secret-out <FILE> --out <FILE> <--daa <SCORE>|--node <URL>>

Options:
      --draft <FILE>                   The draft: hashlock terms in JSON form without hash_lock; a missing nonce is drawn at random
      --network <NETWORK>              Network to act on. Testnet unless mainnet is passed here explicitly [possible values: mainnet, testnet]
      --my-key <HEX>                   Your x-only public key: the terms' seller_key
      --my-counterpart-account <HEX>   Your account on the counterpart chain: the counterpart record's recipient
      --my-refund <PIN>                The exact KCC-20 owner your refund must go to, when it is not --my-key: kcc20:<type>:<hex>
      --daa <SCORE>                    DAA score at creation, as you read it from your node. Testnet only: on mainnet the score is read from --node
      --node <URL>                     wRPC URL of a synced node to read the DAA score from: ws:// or wss://, and on mainnet wss:// or ws:// to this machine
      --counterpart-final-secs <SECS>  The counterpart chain's time to finalized commitment, in seconds, as its source reports it
      --retry-secs <SECS>              The retry window for the Kaspa claim, in seconds [default: 1800]
      --daa-sample <FILE>              A DAA rate sample file (xchain daa-sample); required on mainnet
      --known-hashes <FILE>            This installation's known hash locks; created if missing
      --kas-equivalent <SOMPI>         The trade's value: the KAS value of the larger leg, in sompi. Required, since the asset leg is a KCC-20 token whose KAS value the CLI cannot know
      --i-accept-the-risk              Lift the per-trade value cap for v0.1
      --secret-out <FILE>              Where the secret is written (mode 0600); must not exist. It is never shown
      --out <FILE>                     The hashlock terms file to write; must not exist
  -h, --help                           Print help
```

### `impulse-watch`

```text

Usage: impulse-watch <COMMAND>

Options:
  -h, --help     Print help
  -V, --version  Print version
```

#### `impulse-watch run`

```text
Follow the trades and print one JSON event per line on stdout

Usage: impulse-watch run [OPTIONS] --network <NETWORK> --node <NODE> --finality-depth <N> --state <FILE>

Options:
      --network <NETWORK>        The network watched; the node and every terms file must be on it [possible values: mainnet, testnet]
      --node <NODE>              The node's wRPC (Borsh) URL, ws:// or wss://. On mainnet: wss://, or ws:// to this machine
      --finality-depth <N>       Finality depth N in DAA scores. No default: it is a security choice
      --state <FILE>             The local JSON state file. Replaced atomically after each round
      --init                     Start a new state file. Without it the file must exist; with it the file must not
      --trade <TERMS_FILE>       A terms file to watch (repeat for several trades)
      --linked <SHEET>           A sheet file of `impulse linked new` (repeat for several): both of its trades are watched as ordinary trades, and one `linked` event is reported when the pair's phase changes
      --keep-signed <TX_FILE>    A signed transaction (raw form, hex) to resubmit if a reorg removes it (repeat). The only transactions the watcher ever submits
      --retire <TERMS_HASH>      Stop watching a trade of the state, by terms hash (repeat)
      --retention-daa <DAA>      Evict final acceptances this many DAA scores deep (must be above the finality depth). Without it nothing is evicted
      --poll-interval-ms <MS>    Milliseconds between polls [default: 1000]
      --max-polls <K>            Stop after this many polls (exit 1 if one failed). Without it, run until killed
      --max-failed-polls <K>     End the run (exit 1) after this many polls in a row failed, so that a supervisor sees a watcher that has lost its node. Without it a failed poll is reported and the run goes on
      --log-format <LOG_FORMAT>  The form of the lines on stderr [default: text] [possible values: text, json]
  -h, --help                     Print help
```
