Details

Settlements are self-describing on chain. The page asks the node for the transaction, rebuilds the trade from the vault script each input reveals, checks it against the pinned template, and shows what the node says about it. Nothing is sent anywhere except to that node.

This page's policy allows no other plaintext link than ws:// to a kaspad on this machine, so a node reachable over the internet needs wss://.

A node keeps no index of transactions by ID. The page looks in its mempool, and then, if you give a block, on the chain from that block.
